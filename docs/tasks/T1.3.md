- OPS-01: `docker compose up -d` starts a working system: server image (non-root) plus a bundled database under a Compose profile, used when `DATABASE_URL` is empty (data on a named volume); with `DATABASE_URL` set, the external database is used; migrations run on server start; `/health` reports API and database status.
- OPS-06: optional reverse proxy (Caddy) with automatic HTTPS for `DOMAIN` (apps need HTTPS and WSS in production; WebSocket path `/v1/sync/stream`).
- OPS-02: README first-deploy section now; updating, backup/restore and building installers are written when their pieces exist but the README must have a section stub or a working version of update and backup/restore of the bundled database (restore tested) where cheap.
- From T1.2: the server needs `DATABASE_URL`, `JWT_SECRET`, `REFRESH_SECRET` (32+ chars, no placeholders, different), `PUBLIC_API_URL` (should be required in the deployment), `TRUST_PROXY` (1 behind Caddy), `CORS_ORIGINS`, `DB_PASSWORD` (12+ chars when set); Appendix A says `DATABASE_URL` empty = bundled database, so Compose must inject the bundled URL when it is empty. Shutdown budget 8 s (stop_grace_period 10 s). `/health` returns 503 when the database is down.
- `infra/.env.example` is deny-listed for agents: put the full proposed content in `infra/env.example.proposed` (a normal file) and the report; the owner copies it over.
- Dev compose: `infra/docker-compose.dev.yml` (unchanged, dev only). Port 5432 on this machine is taken by another PostgreSQL; the dev stack runs on 15432 and Mailpit 11025/8025: do not touch it, use a different compose project name and ports for your tests and tear down everything you start.
- Smoke test in CI: add a job or step to `.github/workflows/ci.yml` (and a script under `scripts/`) that builds the image, brings the stack up with a generated `.env`, waits for `/health` ok, restarts to prove migrations are idempotent and data persists, and tears it down. Keep `check.mjs` groups unchanged unless it fits (devops-engineer decides; unit tests for the script's pure parts).
