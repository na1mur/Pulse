### Interfaces

- pnpm workspace packages: `apps/server`, `apps/desktop`, `packages/*`. Every pnpm package defines the scripts `typecheck`, `test`, `build` (and `dev` where it makes sense). Formatting and linting run once from the root over the whole repo, not per package.
- TypeScript packages extend `../../tsconfig.base.json` (strict). Tests: Vitest, next to the code.
- `apps/desktop` build output: `apps/desktop/dist`; Tauri `frontendDist` `../dist`, `devUrl` the Vite dev server, `beforeBuildCommand`/`beforeDevCommand` use pnpm.
- Cargo workspace members: `crates/core` (package `pulse-core`), `apps/desktop/src-tauri` (package `pulse-desktop`). Edition 2024, shared `[workspace.lints]` (clippy warnings denied in the check, not via `#![deny]`).
- Root scripts (slice 6): `pnpm verify` = frozen install + `node scripts/check.mjs`; `check.mjs` runs, in order: docs check, hook tests, Prettier check, ESLint, dependency-cruiser, per-package typecheck/test/build, `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, Android Gradle checks; it can run one group (`--only ts|rust|android|docs`).
- Prettier and ESLint ignore `docs/**` and `.claude/**` (docs have their own check; hooks have their own tests).

### Review focus

- "Fresh clone": nothing depends on files that are gitignored or only present on this machine (e.g. `apps/desktop/dist` must be built before the Tauri crate compiles; `local.properties` must not be required beyond `ANDROID_HOME`).
- Dependency rules of ARCHITECTURE section 2 are expressed in tooling: `pulse-core` has no Tauri/OS dependency; dependency-cruiser forbids server <-> desktop imports and desktop UI -> network.
- One version per language pinned (Node, pnpm, Rust toolchain, JDK/Kotlin/AGP via version catalog).
- Lockfiles committed (`pnpm-lock.yaml`, `Cargo.lock`, Gradle wrapper + version catalog).
- No speculative code: skeletons only, no features.
