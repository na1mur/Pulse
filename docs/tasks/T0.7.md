### 9.3 Performance budgets

| Metric | Budget |
|---|---|
| Start/pause visual feedback | < 100 ms (optimistic) |
| Cross-device propagation | p95 < 1.5 s (target about 1 s) |
| Desktop cold start to interactive | < 1.5 s |
| Android cold start to timer visible | < 1 s (PRD ceiling: 2 s on both apps) |
| Stats for any month | < 500 ms; p95 < 300 ms over 5 years of data (about 20k sessions) |
| Idle CPU with the timer running | Near zero; 1 Hz redraw of the clock only (not the whole screen) |
| Network while idle | Heartbeat only; usage increments at most once a minute while tracked usage happens |
| Charts and other heavy views | Loaded on demand, not in the first bundle |
| Windows installer size | < 15 MB |
| Android APK size (64-bit ARM) | < 15 MB, including the FCM client |
| Desktop memory, closed to tray with the timer running | < 50 MB |
| Activity tracking cost | Desktop: one foreground check every 5 s (UI Automation only when a browser is in front); no measurable CPU at rest. Android: usage events checked at most every 5 s and only while the screen is on; no wake-ups while it is off |

The size and memory figures are targets to confirm with the T0.7 spike; adjust them there if a measured hello-world build cannot meet them.

## Reports
### Slice 1 - desktop (devops-engineer)
Changed only `apps/desktop/src-tauri/tauri.conf.json`: `bundle.active: true`, `bundle.targets: ["nsis"]` (without `active`, `tauri build` makes no installer). Machine: Ryzen 7 5700G, Windows 11, WebView2 155.0.4283.62, busy dev box.

| Metric | Budget | Measured | Method |
|---|---|---|---|
| NSIS installer | < 15 MB | 1.43 MiB | release bundle file size (MSI 2.07 MiB, not used) |
| Installed size | - | 6.05 MB | `pulse-desktop.exe` + `uninstall.exe` |
| Memory, window destroyed, process alive (closed to tray) | < 50 MB | 3.9 MB private (1 process) | spike build that prevents exit on window close; Process V2 private working set of app + WebView2 children |
| Memory, window open / minimized / hidden | - | 71.6 / 73.6 / 76.1 MB (7 processes) | same method, median of 5 |
| Cold start to first contentful paint | < 1.5 s | 474 ms median | spawn to FCP over the WebView2 debug port, 1 warm-up + 5 runs, fresh processes, warm file cache |

Finding: the 50 MB budget holds only if closing to tray destroys the window and keeps the native process alive (`RunEvent::ExitRequested` + `prevent_exit`); `window.hide()` costs about 76 MB. Not measured: cold start after reboot, debug-port overhead, memory with the real core and tray, MSI install, WebView2 bootstrapper download. Measurement scripts stay in the scratchpad (not in the repo).

### Slice 2 - Android and UniFFI (core-engineer)
Built `crates/core-ffi` (UniFFI 0.32.2 proc-macros: `core_version`, `local_day`, a `PulseCore` handle), Gradle wiring (host build, bindgen, `cargo ndk` for arm64-v8a, NDK 27.1.12297006), a Compose hello screen, a `specialUse` foreground service that starts the core and idles, and `firebase-messaging` with dummy `FirebaseOptions` built in code (auto-init off, `FirebaseInitProvider` removed, D-23). Tests: 5 Rust, 4 Kotlin through the real bindings. Green: fmt, clippy, `cargo test --workspace` (67), ktlint, detekt, lint, unit tests, `assembleRelease`.

| Metric | Budget | Measured | Method |
|---|---|---|---|
| APK, arm64-v8a, R8 + shrink, incl. FCM | < 15 MB | 2.06 MB unsigned | `assembleRelease` file size (dex 0.88 MB compressed, core `.so` 0.71 MB, JNA 0.17 MB) |
| Cold start to first frame | < 1 s | 543 ms median (496-573) | **x86_64 emulator** (Pixel 6 AVD, API 35, WHPX), `am start -W`, 6 cold runs; not arm64 |
| Service process memory, 60 s idle | none yet | 19.4 MB PSS | x86_64 emulator, `dumpsys meminfo`, activity only backgrounded |

Not measured: arm64 cold start and memory (no arm64 device here), service memory with the activity destroyed, screen-off battery and wake-ups, a real `getToken` on a Play-services phone. Spike stand-ins to replace later: eager FCM init in `Application.onCreate` (real: lazy, only with push config), service auto-start from `MainActivity` (real trigger: MOB-02), `versionCode = 1` (MOB-05).
